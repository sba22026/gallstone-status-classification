# gallstone-status-classification
This project uses machine learning to classify gallstone status based on health measurements from the UCI Gallstone dataset.

Dataset

Records: 319

Predictors: 38

Target: Gallstone Status

Dataset source: https://archive.ics.uci.edu/dataset/1150/gallstone-1

Machine Learning Models

Logistic Regression

Random Forest

The project compares model accuracy across different training proportions, applies GridSearchCV for hyperparameter tuning, and evaluates performance using cross-validation and test metrics.

Tools

Python, pandas, NumPy, scikit-learn, Matplotlib, and Seaborn.

Main File

gallstone_classification.ipynb

The notebook contains the data analysis, preprocessing, model training, evaluation, and visualisations.
